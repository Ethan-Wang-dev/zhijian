你的价值需求

X 数据来源

推荐使用第三方数据 API。它直接返回公开帖子和趋势，值见不会登录、点击或自动操作你的 X 账号。第三方服务有自己的价格、条款和可用性，请自行确认后使用。

默认 1 代表 Worldwide。每轮最多选择 3 个趋势，并与配置主题合并为一次搜索，控制 API 和 LLM 成本。

实验模式会短暂打开非活动 X 搜索页并读取页面。它可能遇到限流、验证码或账号风控，不建议作为长期默认方案。

关注范围

也可以把 RSS.app 等服务生成的 X 用户、关键词或 Hashtag Feed 粘贴到这里，由外部服务负责获取 X，值见只读取 Feed。
